# api-request

Menjalankan API — memanggil API layanan lewat HTTP.

Memanggil API layanan (GET/POST) untuk membaca atau mengubah data.

Cara pakai: gunakan terminal (curl) atau CLI konektor yang tersedia untuk layanan tersebut. Ikuti dokumentasi konektor yang ada; jangan menebak endpoint atau kredensial. Kredensial/API key hanya lewat Secure Vault atau konektor resmi, tidak pernah ditulis di chat atau file biasa.

Verifikasi: periksa status dan isi respons sebelum melaporkan hasil; berhenti bila API mengembalikan 429/403 (rate limit/blokir).
