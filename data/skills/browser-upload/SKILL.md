# browser-upload

Upload file — mengunggah file ke website lewat browser.

Mengunggah file ke website melalui browser.

Cara pakai: gunakan tugas browser (browser.browse) dengan field files — sertakan file dari workspace beserta tujuannya di situs (mis. kolom/formulir mana). Jangan sertakan kata sandi atau data privat yang tidak dibutuhkan.

Verifikasi: pastikan situs mengonfirmasi file diterima sebelum melaporkan selesai.
