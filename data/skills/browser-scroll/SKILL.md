# browser-scroll

Scroll halaman di browser — gulir halaman web ke atas/bawah untuk melihat konten.

Menggulir halaman web di browser agar konten yang berada di bawah/atas terlihat.

Cara pakai: gunakan tugas browser (browser.browse) dan instruksikan untuk scroll ke bagian halaman yang dimaksud (mis. scroll ke bawah sampai elemen tertentu terlihat). Bila perlu memastikan konten termuat, tunggu halaman selesai dimuat dulu.

Verifikasi: baca kembali isi halaman setelah scroll untuk memastikan bagian yang dicari sudah terlihat.
