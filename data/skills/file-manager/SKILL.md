# file-manager

Mengelola dokumen — membaca, membuat, mengedit, dan mengatur file.

Mengelola file dan dokumen di workspace: membaca, membuat, mengedit, memindah, dan mengatur file.

Cara pakai: baca dengan muse.read, tulis baru dengan muse.write, ubah sebagian dengan muse.edit, dan operasi berkas lewat terminal (muse.exec). Simpan dokumen pengguna di ~/workspace/your_files/ atau folder tujuan yang sudah ditentukan; file kerja internal di hidden_files/ terkait.

Verifikasi: baca kembali file setelah ditulis/diubah untuk memastikan isinya benar.
