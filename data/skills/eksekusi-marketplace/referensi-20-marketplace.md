# Referensi 20 Marketplace — syarat, komisi, payout, kecocokan

Diriset 22 Nov 2026. Angka adalah ketentuan yang dipublikasikan tiap platform, bukan janji pendapatan. Bila ragu, cek ulang situs resminya sebelum eksekusi.

## Kelompok A — AI Agent & otomatisasi

**1. Swarms Marketplace (swarms.world)** — Jual AI Agent, prompt, tools, MCP Server, Skills (format SKILL.md). Listing gratis, tanpa antrean persetujuan. Penjual **90%** (fee 10%). Publish via API: `POST /api/v1/publish/product` type `prompt` (TIDAK ada endpoint khusus skill); wajib name, prompt (isi SKILL.md), useCases ≥1, tags; `is_free:false, price_usd:12`; butuh API key dari swarms.world/platform/api-keys. ~6.400 produk, 808 seller (Okt 2026). Produk kita: skill Pusat Komando $12. Status: paket SIAP.

**2. Agensi.io (agensi.io/sell)** — Marketplace AI Skills. Listing gratis. Kreator **70%**. Satu kali beli + langganan. Review keamanan + AI + manusia sebelum live. Produk kita: skill Pusat Komando $12. Status: harga diputuskan; balasan $12 ke Joeri (joeri@agensi.io) menunggu Setuju teks persis Cipta.

**3. MCP Market (mcpmarket.com)** — Situsnya Hub pengelolaan/versioning skill & MCP (Free $0 / Pro $19/bln / Team $149/bln), BUKAN toko jualan. Tidak ada jalur jual terverifikasi. ChatGPT mengklaimnya marketplace — bertentangan dengan cek langsung. Status: verifikasi ulang bila ada jalur jual.

**4. Neura Market (neura.market)** — Workflow n8n, Make, Zapier + prompt. Kreator **80%** (Starter, komisi 20%) → 85% Performer → 90% Rainmaker. Listing $0. 5.000+ workflow. Produk kita: workflow/prompt (perlu disiapkan). Status: belum dieksekusi.

**5. Apify Store (apify.com/store)** — Actor (scraper, automasi, tools AI). Penjual **80%** dari revenue dikurangi biaya platform. Payout ~$1,5 jt/bulan ke ±3.900 developer (klaim Apify). Produk kita: bukan Actor — belum cocok.

**6. Salesforce AgentExchange (appexchange.salesforce.com)** — Marketplace Agentforce enterprise. Butuh kemitraan Salesforce. Produk kita: belum cocok untuk penjual individu.

**7. AWS Marketplace (aws.amazon.com/marketplace)** — Software/SaaS enterprise. Butuh registrasi seller AWS + verifikasi bisnis. Status: riset dulu.

**8. Microsoft Marketplace (marketplace.microsoft.com)** — Aplikasi bisnis + Copilot Agents. Butuh Partner Center + verifikasi. Status: riset dulu.

## Kelompok B — Aplikasi, website, software, kode

**9. Envato Market (envato.com)** — Tema, plugin, video, musik, desain. Pendaftaran author baru **DIJEDA sejak 6 Nov 2026** (Theme & Code tidak masuk rencana buka kembali). Komisi flat **50%** (sejak 1 Jul 2026). Payout PayPal/Payoneer/SWIFT, min $50, tgl 15. Produk kita: aplikasi HTML ✅, game HTML5 ✅, Pusat Komando Python ❌. Draf: Kasir Toko $59.

**10. CodeCanyon (codecanyon.net)** — Source code, script, aplikasi, plugin. Pendaftaran author **DITUTUP, invitation-only** (Code tidak diundang saat ini). Komisi flat **50%**. Payout PayPal min $50. Review ketat: Live Preview wajib, dokumentasi HTML wajib, tanpa CDN, kode tidak di-minify, dukungan 6 bulan. Produk kita: aplikasi HTML ✅ paling cocok. Draf: Kasir Toko $59.

**11. Codester (codester.com)** — Source code, aplikasi, game, script, template. Daftar **gratis**, tanpa biaya listing. Penjual **70%**. Payout PayPal/Skrill atas permintaan, min $50 (di bawah $50 cair setelah 12 bulan). Review 1–2 hari kerja; **item tanpa dokumentasi pasti ditolak**. Upload: main .zip + dokumentasi, preview 800×400, icon 200×200, screenshots .zip, URL demo. Produk kita: aplikasi HTML ✅, game ✅ (harga pasar $24–$49), Pusat Komando Python ✅ kategori (harga $12 di bawah pasar). Draf + paket: Faktur & Invoice $29 — SIAP.

**12. Unity Asset Store (assetstore.unity.com)** — Aset game Unity (model 3D, tools C#, template). Publisher: Unity ID + upload dari Unity Editor (.unitypackage/UPM); review min 5 hari kerja. Bagi hasil **70/30**. Harga min $4,99. Payout PayPal bulanan / wire triwulanan min $250. Wajib tax interview (W-8BEN). Konten AI wajib diungkapkan. Produk kita: ❌ apa adanya (HTML/Python bukan aset Unity). Satu-satunya celah: port game jadi template Unity ($19–$49) — pekerjaan besar, butuh keputusan Cipta.

## Kelompok C — Produk digital & kreatif

**13. Gumroad (gumroad.com)** — Produk digital apa saja. Fee 10% + $0,50 (Discover 30%). Payout bank BCA mingguan, min $100. Status: **LIVE** (satukiki.gumroad.com) — isi produk.

**14. Creative Market (creativemarket.com)** — Font, template, ilustrasi, grafis, desain. Toko dibuka lewat **Shop Request** (review manusia); butuh portofolio ONLINE 10–20 karya (Behance/Dribbble). Penjual **50%**. Harga min Graphics $6/$9, Photos $3/$4. Non-US kena withholding 30% (pembeli AS) sampai W-8BEN tervalidasi. Payout PayPal. AI diizinkan dengan label. Price parity: dilarang pasang harga di atas harga terendah di tempat lain. Produk kita: 14 item (8 ilustrasi POD $12, cover $15–$18, paket foto $15–$29; total $222 bila terjual 1×). Status: draf siap; butuh Behance + persetujuan harga + nama toko.

**15. Etsy (etsy.com)** — Handmade + digital download. Listing $0,20; komisi 6,5% + processing 4,5% + Rp7.000. Buka toko butuh bank BCA + KTP + selfie + 2FA + ≥1 listing; setup $19 DILEWATI. Produk kita: eBook cerita nabi Inggris + POD (kata kunci + 10 draf listing siap). Status: akun saja, belum ada toko.

**16. PromptBase (promptbase.com)** — Prompt AI (~330.000 prompt). Komisi **20% marketplace, 0% link sendiri** (0% setelah 5+ penjualan). Harga satuan $2,99–$4,99 (median $5,99). Penjual baru maks $19,99. Review 15 mnt–36 jam. Payout Stripe (atau Zoneless), min $30, akun min 30 hari. Agent skills dijual sejak Mei 2026. Listing harus TEMPLATE dengan [variabel] + 4–9 contoh output + panduan. Produk kita: 9 listing (total $50,96 bila terjual 1×; bersih ±$40,77) + skill $12. Status: draf siap; butuh persetujuan harga + akun belum dibuat; risiko payout Stripe (Cipta tanpa kartu kredit) belum jelas.

**17. Payhip (payhip.com)** — Ebook, kursus, membership, software. Fee 5% (Free Forever). Payout PayPal. Status: **LIVE** — 6/10 produk fase 1 (Rindu $5; Yunus/Nuh/Yusuf/Musa/Ibrahim $4,99); 4 tertahan kartu persetujuan.
