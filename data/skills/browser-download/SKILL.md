# browser-download

Download file — mengunduh file dari website ke perangkat.

Mengunduh file dari website.

Cara pakai: gunakan tugas browser (browser.browse) dan minta unduh file yang dimaksud; file hasil unduhan masuk ke folder browser_downloads. Bila butuh membaca isinya, baca file hasil unduhan tersebut.

Verifikasi: pastikan file benar-benar terunduh (ada dan ukurannya wajar) sebelum dipakai atau dilaporkan.
